Kết luận: thư mục log root:<nhóm site> 0750 thì worker nginx (www-data) không tự mở lại được file log khi
nhận USR1 (phải đi qua thư mục), nên sau khi xoay vòng log mới vẫn rơi vào access.log.1 và tiến trình chính
đổi chủ access.log sang www-data. Gửi HUP thì tiến trình chính (root) mở file rồi sinh worker mới thừa kế
file đã mở: log ghi đúng access.log, chủ file giữ nguyên root. Postrotate của nhánh nginx phải dùng HUP.
