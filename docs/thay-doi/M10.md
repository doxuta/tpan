# M10: chuyển LEMP ⇄ LAMP — ghi chú thay đổi

File này do phiên của mốc M10 viết (chạy song song, mục 6.4 của `agent-dev/CHAY-NHIEU-AGENT.md`). Phiên điều phối gộp nó vào `docs/KE-HOACH.md` khi ghép rồi xoá file.

Mốc M10 (mục 13): chuyển LEMP ⇄ LAMP tại chỗ (mục 6.6). Xong khi: e2e bước 8 (`stack switch --to apache` → cả 3 site vẫn 200; chuyển ngược lại → vẫn 200); đo được thời gian gián đoạn. Việc riêng phiên điều phối giao: sinh lại vhost của mọi site bằng `core.siteVhost` (site có SSL thì bản 443, socket theo bản PHP của từng site), site mặc định cổng 80 và 443 (M5), file logrotate theo web server, phép kiểm lệch của M4 nhận các file mới làm chuẩn, nguồn nginx.org (M12: worker dưới user `nginx` thuộc nhóm `www-data`), `policy-rc.d` chặn khởi động nhưng không chặn `enable` (mục 16).
