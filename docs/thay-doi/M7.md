# M7: cổng cho agent

File này là phần của M7 mà phiên điều phối gộp vào `docs/KE-HOACH.md` lúc ghép (mục 6.4 của `agent-dev/CHAY-NHIEU-AGENT.md`): bảng chia việc, chỗ thực tế khác đặc tả, kết quả kiểm cho mục 16, và việc chủ dự án tự làm.

## Mốc này làm gì

Cổng cho agent (mục 8.1, 8.3, 11 và 12 của KE-HOACH.md): danh mục công cụ có kiểu (`internal/tools`), che dữ liệu (`internal/ai`), `tpan mcp` chạy MCP server qua stdio, bảng `plans` cho Plan chờ duyệt kèm nguồn gốc, hai chế độ duyệt (`panel`, `client`), `tpan plan list|show|approve|reject`, API và màn duyệt Plan chờ duyệt, nút "Chép lệnh cho Claude Code", thư mục `agents/`.
